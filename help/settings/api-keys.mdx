---
title: "Bring your own API key"
description: "Store your own OpenAI or OpenRouter API key in Nitrogen AI to use your own credits for AI generation. Keys are validated live, encrypted at rest, and never exposed in plain text."
---

Nitrogen AI lets you connect your own API key so AI generation runs against your own provider account instead of the platform's managed credits. Once you add a key, your account moves to the BYOK tier with no Nitrogen AI usage cap — you pay your provider directly for what you use.

## How it works

When you save a key, Nitrogen AI validates it with a live call to the provider before storing it. If the key is invalid or lacks permission, you'll see an error and nothing will be saved. Valid keys are encrypted at rest. The UI shows only a masked preview, e.g. `sk-ab...xyz1`.

Adding a key automatically upgrades your account from the trial tier to the BYOK tier. Removing your last remaining BYOK key reverts your account to the trial tier, unless you also have an active Stripe subscription.

## Adding an API key

<Steps>
  <Step title="Open API key settings">
    Go to **Settings → API Keys**.
  </Step>
  <Step title="Choose a provider and paste your key">
    Select **OpenAI** or **OpenRouter**, then paste your key into the input field.
  </Step>
  <Step title="Save the key">
    Click **Save**. Nitrogen AI validates the key with a live call to the provider. If it passes, the key is encrypted and stored and your account is upgraded to the BYOK tier.
  </Step>
</Steps>

<Note>
  Validation calls the provider's models endpoint. Make sure your key has at least read access — keys with no permissions will fail validation.
</Note>

## Viewing stored keys

Go to **Settings → API Keys** to see your stored keys. Each entry shows the provider, a masked key preview, and the date it was saved. The full key is never displayed after saving. To rotate a key, delete the existing entry and add the new one. You can have one stored key per provider.

## Removing an API key

From **Settings → API Keys**, click **Delete** next to the key you want to remove. This action cannot be undone.

<Warning>
  Removing your only remaining BYOK key reverts your account to the trial tier immediately, unless you have an active Stripe subscription. If you have keys stored for both supported providers, removing one leaves you on the BYOK tier as long as the other remains.
</Warning>

## Supported providers

Nitrogen AI currently supports **OpenAI** and **OpenRouter** as BYOK providers.

<Accordion title="What happens if I already have a Stripe subscription and add a BYOK key?">
  Your Stripe subscription stays active. Adding a BYOK key doesn't cancel your paid plan. AI requests route through your own key while it's present. If you later remove the key, your subscription tier is preserved.
</Accordion>
