Nitrogen AI uses Firebase Authentication to manage user identity. When you sign in through the app, Firebase issues a short-lived ID token that you include in API requests.

## Signing in

Go to [app.the-nitrogen.ai](https://app.the-nitrogen.ai) and sign in with your email address and password. If your organization uses a supported identity provider, you can sign in through SSO instead.

The app manages your session automatically — you don't need to handle tokens manually when using the Nitrogen AI interface.

## Authenticating API requests

Every request to the Nitrogen AI API must include a valid Firebase ID token as a Bearer token:

```http
Authorization: Bearer <your-firebase-id-token>
```

To retrieve your token for direct API use, call `getIdToken()` from the Firebase client SDK after authenticating. Tokens expire after one hour — call `getIdToken(true)` to force a refresh, then retry.

<Warning>
  A `401 Unauthorized` response almost always means your token has expired. Refresh it before investigating further.
</Warning>

## Bringing your own API key (BYOK)

If you want AI generation to route through your own provider account instead of the platform's managed credits, add your key in **Settings → API Keys**.

1. Go to **Settings → API Keys**
2. Select **OpenAI** or **OpenRouter** and paste your key
3. Click **Save**

Nitrogen AI validates the key before saving. Once saved, the platform shows only a masked preview. Your key is stored encrypted and never exposed in plain text.

Adding a key upgrades your account to the **BYOK tier**, removing any Nitrogen AI usage cap. Removing your last key reverts your account to the trial tier. See [Billing](/settings/billing) for plan details.

## Billing tiers

| Tier | Description |
|---|---|
| **Trial** | Default for new accounts. Limited messages and a small spend cap. No payment required. |
| **BYOK** | Bring your own API key (OpenAI or OpenRouter). You pay your provider directly. Unlocked by adding a key in Settings → API Keys. |
| **Individual** | Full platform access with Nitrogen AI-managed credits, billed monthly through Stripe. |

## Authentication errors

| Status | Meaning | Fix |
|---|---|---|
| `401` | Token missing, invalid, or expired | Refresh your Firebase ID token and retry |
| `403` | Authenticated but no permission for this resource | Check your role on the project |
| `503` | Auth service temporarily unavailable | Wait and retry |
