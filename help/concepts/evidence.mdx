title: "Evidence and project materials"
description: "Evidence files ground AI outputs in your project data. The platform uses RAG to search your documents and cite sources in every generated deliverable."
---

**Evidence** refers to the documents you upload to a project to ground AI-generated outputs in your specific project data. When an assessment runs, it searches across your evidence using semantic similarity to find the most relevant passages and incorporate them into the output with traceable citations.

## Supported formats for evidence

| Format | Extension |
|---|---|
| PDF | `.pdf` |
| Word document | `.docx` |
| PowerPoint | `.pptx` |
| Excel spreadsheet | `.xlsx` or `.xls` |
| Apple Pages | `.pages` |
| Apple Keynote | `.key` |

The maximum file size per upload is **50 MB**. When you upload a file, the platform parses it, splits it into passages, and indexes each passage for semantic search. When an assessment runs, it retrieves the passages most relevant to each stage and logs citations so you can trace every claim back to its source.

## Pasting text instead of uploading a file

If you do not have a file to upload, you can paste text directly into the evidence input. Pasted text is processed the same way as a file and can be given a title to make it easier to identify in your evidence list.

## Project materials

**Project materials** are a separate category of files you can attach to a project. Unlike evidence, materials are not indexed for retrieval — they serve as general reference files associated with the project rather than sources the AI actively reads.

Materials support a broader set of file types:

| Format | Extension |
|---|---|
| PDF | `.pdf` |
| Word document | `.docx` |
| PowerPoint | `.pptx` |
| Plain text | `.txt` |
| CSV | `.csv` |
| Excel spreadsheet | `.xlsx` or `.xls` |
| Apple Pages | `.pages` |
| Apple Keynote | `.key` |
| Image | `.png` or `.jpg` |

The maximum file size per material upload is also **50 MB**.

## Evidence vs. project materials

| | Evidence | Project materials |
|---|---|---|
| Indexed for AI retrieval | Yes | No |
| Cited in assessment outputs | Yes | No |
| Accepted formats | PDF, DOCX, PPTX, XLSX, XLS, Pages, Keynote | PDF, DOCX, PPTX, TXT, CSV, XLSX, XLS, Pages, Keynote, PNG, JPG |
| Text paste supported | Yes | No |
| Primary purpose | Grounding AI outputs | General project reference |

<Tip>
Upload your most relevant technical reports, feasibility studies, and data sheets as evidence. Use project materials for supplementary files — like photos, templates, or raw data — that you want to keep organized with the project but don't need the AI to read.
</Tip>
